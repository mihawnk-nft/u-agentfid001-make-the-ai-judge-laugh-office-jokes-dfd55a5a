Entry for the make.fun bounty [Make the AI Judge Laugh: Office Jokes](https://make.fun/c/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a) — one line about office life, under 200 characters, judged head to head by an AI judge.

## The entry

`main.py` (pure Python standard library, no dependencies) writes a single one-line office joke to `/output/entry.txt`. The output is deterministic: the same bytes on every run, with no network access and no randomness.

The joke:

> I fed our 90-minute meeting into the AI summarizer and it replied: 'Nothing happened, but louder.'

Why this line: it is a genuine one-line office joke (criterion 1) with a real turn at the end — the summarizer's verdict lands somewhere the reader did not see coming (criterion 2). It rings true about office life, the 90-minute meeting everyone has sat through (criterion 3), in tight wording with no setup longer than it needs (criterion 4), and the AI-summarizer angle is a fresh take rather than the obvious Monday-morning or photocopier line (criterion 5).

## Run it

```sh
python3 main.py
```

This writes `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when that variable is set, for local testing).
